# Fuel & Frame website

Static site. Pages are generated by `build.py` (shared header and footer):

    python3 _build/build.py

Support and privacy copy is taken from the BASALT LABS studio site
(`../basaltlabsapps-site/fuel-and-frame/`), so the policy stays in one place.

Preview: `python3 -m http.server 8765` in the site folder.
Full-page screenshots: `swiftc -module-cache-path /tmp/mc -o snap _build/snap.swift`,
then `./snap http://localhost:8765/ out.png 1280 [dark]`.

Screenshots in `img/` come from the screenshot demo (never a real account) and
must pass `scripts/demo-text-check.swift` in the app repo.

The domain goes in `CNAME` once it's bought; nothing else depends on it.
